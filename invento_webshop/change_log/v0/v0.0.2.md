# Changelog

## [0.0.2] - 2026-09-27

### 🐛 Fixed
- Fixed guest checkout crashing in `place_order` → `create_user` (`webshop_functions/cart.py`) whenever the site's default outgoing Email Account had a corrupted/missing stored password. `User.after_insert` was auto-sending a welcome email, and the `ValidationError` raised by `get_password()` for the broken Email Account was never caught (only `frappe.OutgoingEmailError` is), so it aborted the whole order. Guest signups now insert with `send_welcome_email: 0` and `flags.no_welcome_mail = True`, so checkout no longer depends on outgoing email working at all.
